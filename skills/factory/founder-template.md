# Founder profile

Every agent reads this file. Keep it current, because the judge scores founder fit against it and the strategist sizes the 30 day plan to the hours and budget below.

* Team: solo founder
* Background: not set (for example software, sales, legal, design)
* Based in: not set
* Markets: decided per run (Brazil, the US or another market named in the idea)
* Hours per week for validation: not set
* Budget for 30 days of validation: not set
* Goal: not set (for example a monthly revenue target, bootstrapped or funded)
* Will not do: not set (for example cold calls, regulated industries, hardware)
* Tools already in use: not set

The first run asks for anything marked "not set" that it needs and saves the answer here.
